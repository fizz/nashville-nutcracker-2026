# Nashville Ballet Nutcracker Youth Schedule Helper

A small parent-built static web app that turns the youth-cast master schedule into a dancer-specific schedule.

## What it does

Parents choose:
- dancer role
- cast color

The app returns:
- rehearsals
- fittings
- tech / dress calls
- performances
- call times
- locations
- production notes
- downloadable `.ics` calendar file

## Cast rules encoded

- Party Boys: double cast — Red / Green
- All other youth roles: triple cast — Blue / Purple / Yellow

## Important

This is an unofficial parent-built helper. Nashville Ballet's official notices and schedule updates always take priority.

Last updated: November 1, 2026.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `nutcracker-schedule`.
2. Upload or push the files in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Save.

GitHub will show the public URL after deployment.

Typical project URL:

`https://YOUR-GITHUB-USERNAME.github.io/nutcracker-schedule/`

## Local preview

Just open `index.html` in a browser.

No build step, package manager, framework, server, or backend is required.
